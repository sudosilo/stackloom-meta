Stackloom

Stackloom is a browser game about running a software studio. It is for people who like management games.

You take orders, run terminals, hire agents and developers, and grow your offices. Version 2 adds a product line and a Hackerdoku campaign with a botnet, tools, and ranks.

Live at stackloom-meta.vercel.app.
