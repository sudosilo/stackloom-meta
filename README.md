Stackloom

Stackloom is a browser game about running a software studio. It is for people who like management games.

You take orders, run terminals, hire agents and developers, and grow your offices. Version 2 adds a product line and a Hackerdoku campaign with a botnet, tools, and ranks. Version 3 adds a bubble shooter line, a card deck line for solitaire and video poker, and premium art orders that pay almost double.

Live at stackloom-meta.vercel.app.
